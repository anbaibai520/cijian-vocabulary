## 英文优先录入

“添加单词”默认只显示英文输入框。输入后立即查询内置 5 万条 ECDICT 常用词资料，自动填写中文义、音标、英文释义、词性和有明确记录的词形。预览区显示已匹配资料和缺失项。

开启“联网补充例句和近义词”时，在停止输入 700 毫秒后向 Free Dictionary API 和 Datamuse 请求当前英文词，不上传词库和笔记。此选项可关闭，选择会记住。网络失败不妨碍本地保存。缺失资料不会编造；未匹配到中文义时可先保存英文草稿。

点击“编辑释义与例句”展开详细字段；词族、搭配、同义词笔记、专项题和其他义项各在折叠区。修改英文时清除上一轮自动填入的内容，但保留手写字段。手工修改的字段不会被稍后返回的网络结果覆盖。

批量录入也支持仅粘贴每行一个英文单词，自动使用本地词库补全；已有字段保留，未收录词保留草稿。为避免大量请求，批量录入只用本地资料。

本地词库来自 https://github.com/skywind3000/ECDICT ，从完整 CSV 按 BNC / 当代频率筛选 5 万词，原数据许可见 ECDICT-LICENSE.txt。dictionary-data.js 是只读数据，不写入用户词库存储；可用 tools/build_dictionary.py 重新生成。原始词库可能含旧义项或专业义，多义词应按具体阅读语境调整。该数据不提供完整例句、搭配和同义词细微辨析。

## 开始使用

1. 双击 `打开学习器.cmd` 或 `index.html`，使用新版 Edge 或 Chrome。
2. 点击“加载 4 个示例词”体验，或点击“添加单词”建立自己的词库。
3. 添加时只需输入英文；详细编辑在折叠区中，可补充词族、搭配、原文和个人例句、近义词差异。
4. 进入“今日学习”完成主动回忆。看答案后按真实情况评分。
5. 在“数据与设置”定期导出 JSON 完整备份。

数据保存在当前浏览器的 localStorage，不会自动写回程序文件夹。清理浏览器数据、换浏览器、移动程序路径可能影响数据，请先导出备份。文件夹里的“英语背词应用功能规划.docx”是功能规划。

可选稳定地址启动：安装有 Node 时，在此目录运行 `node server.cjs`，访问 `http://127.0.0.1:8765`。直接文件模式与服务器模式使用不同浏览器存储，切换前导出并恢复备份。服务器只在本机监听。

## 评分与复习

答错：10 分钟后；模糊：1 天后；正确：逐步进入 1、3、7、14、30、60 天；轻松：对应间隔乘 1.5。每轮最多 24 题，尽可能穿插不同单词。退出后已评分结果保留，尚未评分不计入记录。

拼写/填空只忽略大小写与多余空白，不做模糊匹配。词义和造句靠个人自评；本版没有语法自动评分，没有推算掌握概率。原句填空是巩固练习。新语境题来自人工录题或自编题库，反复练过后也不代表未见过的迁移测试。

## 录入格式

直接粘贴：每行 `英文<Tab>中文义`。也可每行只有英文，之后补全释义。

CSV 首行字段：`word,meaning,phonetic,pos,definition,example,personal,family,collocations,synonyms,source,tags`。只要求 word；字段中有英文逗号、引号、换行时按 CSV 标准加引号。Excel 请另存为 UTF-8 CSV；此版本不直接读取 XLSX。参考 `示例导入.csv`。

可选专项列：`morphologyPrompt,morphologyAnswer,synonymPrompt,synonymAnswer,transferPrompt,transferAnswer`。兼容 ECDICT 的 `translation` 中文义列（小文件上限 2 MB），并保留音标与英文定义；未内置完整 ECDICT 数据。

JSON 恢复会替换当前数据，页面会先确认；CSV 导入会合并，已有词跳过。本地数据损坏时暂停写入以保护原始内容，可以导出原始数据寻求修复。

## 词典与网络

点击“查询近义词候选”会向 https://api.datamuse.com 发送当前词，确认后追加到笔记而非覆盖原文。词间使用 Datamuse API 作为候选来源，服务说明见 https://www.datamuse.com/api/ 。候选可能跨义项，需自行辨析。

基础功能离线可用。开启联网补全时，输入英文后会请求 Free Dictionary API，将当前词发送至 https://api.dictionaryapi.dev 。也可在更多候选中手动查询。可能受网络和服务可用性影响，失败时可继续手动录入。例句和近义词需自己核对，中文义主要来自本地 ECDICT，保存时保留来源与许可说明。

词典内容许可与软件代码许可不同。Free Dictionary API 返回的 sourceUrls、license 被保留；再分发内容时请核对对应原始许可。浏览器发音由操作系统提供，并非词典真人录音。
